EVENT SIGN UP — FIREBASE SETUP

This build uses private-link-only participant management.

1. Firebase Console > Realtime Database > Rules
2. Replace the current rules with firebase-rules.json from this build.
3. Click Publish.
4. Test with a NEW event after publishing.

How participant management works
- The normal public signup link can create a signup but cannot reopen or edit an earlier signup, even on the same device/browser.
- Each new signup gets a 64-character private management token.
- The private Manage Signup URL is the only participant link that can read/change/cancel that signup.
- Claims containing the private token are NOT publicly readable. Public availability is stored separately as booleans.
- Teacher/organizer access still works through the event owner account.

EMAIL STATUS
Automatic confirmation email delivery is NOT connected yet. During testing, the confirmation screen shows the private link once so you can copy/save it. After a secure email service is connected, that same private link can be emailed automatically and removed from the confirmation screen.
