EVENT SIGN UP — FIREBASE SETUP

1. Open Firebase Console > Realtime Database > Rules.
2. Replace the rules with firebase-rules.json from this build.
3. Publish the rules.

This version adds:
- claimable signup spots / capacity protection
- private participant management links
- shareable editor links
- editor sessions that can view the signup list and remove registrations
- owner-only event editing/deletion and editor-link creation/revocation

The shared editor can optionally link the event to that browser/account's own Schedule Timer Special Schedule.
