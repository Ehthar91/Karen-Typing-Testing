GLN Event Sign Up — Automatic Email + SMS Setup (TEST REPOSITORY)
===============================================================

WHAT THIS BUILD DOES
- Saves the signup first.
- Calls a Firebase Cloud Function to email the private Manage Signup link with Resend.
- If the participant checks the SMS option, calls a second Cloud Function to text the same private link with Twilio.
- If email delivery fails, the private link stays visible on the confirmation screen as a fallback.
- API keys are NEVER stored in the GitHub Pages front end.

TEST LINK BASE
This build defaults private links in email/SMS to:
https://ehthar91.github.io/Karen-Typing-Testing/

Later, change EVENT_SIGNUP_BASE_URL to https://glnkarentypingcenter.com/ when you move to the main site.

BEFORE DEPLOYING FUNCTIONS
1. Firebase Cloud Functions deployment requires the Firebase project to support Cloud Functions billing.
2. Verify glnkarentypingcenter.com in Resend and create a Resend API key.
3. For SMS, create/configure Twilio Programmable Messaging and a Messaging Service with a sender. U.S. carrier registration/verification requirements may apply.

TERMINAL — EMAIL FIRST
From the project root:

  npm install -g firebase-tools
  firebase login
  firebase use gln-karen-typing-center
  firebase functions:secrets:set RESEND_API_KEY
  cd functions
  npm install
  cd ..
  firebase deploy --only functions:sendEventSignupEmail

The default sender is:
GLN Event Sign Up <events@glnkarentypingcenter.com>

If you want a different sender, Firebase parameters can override EVENT_SIGNUP_FROM_EMAIL during deployment.

TERMINAL — ADD SMS LATER
Set the three Twilio secrets:

  firebase functions:secrets:set TWILIO_ACCOUNT_SID
  firebase functions:secrets:set TWILIO_AUTH_TOKEN
  firebase functions:secrets:set TWILIO_MESSAGING_SERVICE_SID
  firebase deploy --only functions:sendEventSignupSms

TEST
1. Open the Event Sign Up on the GitHub test site.
2. Enter Parent/Guardian Name + Email.
3. Optional: enter a phone number and check “Text me the confirmation and private management link.”
4. Pick a slot and save.
5. The reservation should save even if delivery is not configured.
6. Once email succeeds, the fallback private link hides and the page says Email sent.
7. If SMS was selected and succeeds, the page also says Text sent.

IMPORTANT
- Do not put Resend/Twilio secrets in firebase-config.js, event-signup.js, GitHub Secrets exposed to Pages, or any browser code.
- This build does not require new Realtime Database security rules. The Cloud Functions use the Firebase Admin SDK on the server.
- Keep the fallback private link visible until email delivery is confirmed.
